# hello-world

A lightweight hello-world web server using only the Python standard library — no dependencies required.

## Run

```sh
python3 server.py
```

The server listens on `0.0.0.0:8000` and responds with `Hello, World!` to every request.

## Example

```sh
$ curl http://127.0.0.1:8000/
Hello, World!
```

Press `Ctrl+C` to stop the server.
